# TAB format

`.tab` is the input format of Wayne Cripps's `tab` program. Oud reads and
writes that format and adds no syntax of its own (maintainer decision,
2026-09-29). Content the format cannot hold goes to a sidecar file with a
warning (`TODO.md` `C15`).

## Reference

- Manual: `README` in <https://github.com/mandovinnie/Lute-Tab> (the Dartmouth
  pages are gone). Version checked: `tab` 4.3.108.
- The program's license forbids commercial use and requires its notice on
  copies. Do not vendor its source, fonts, or sample files here. Write fixtures
  by hand.
- Reference parser: build the program (`make`, g++ only) and run
  `TABFONTS=<checkout> ./tab -v file.tab -o out.ps`. Each `pass1: ... l:` line
  in the output is one parsed chord: flag, second character, then positions
  1–9. `./tab -ascii file.tab -o out` writes a text rendering. Integration tests
  that use the program must be marked and skip when it is absent.

## Line structure

A chord line starts with a flag or line type (`0`–`5`, `W`, `w`, `B`, `L`, `x`,
`#`, `b`, `S`, …). An optional modifier may follow it: `.` dot, `#` grid, `*`
dot in grid, `|` extra flag bar, `!` no flag, `-` place marker, `Q`/`@`
highlight, `B` dot before. Then come nine note positions, one character each:

| Position | Meaning |
|---|---|
| 1–6 | Courses 1–6, top line first |
| 7 | Bass courses 7 and up, below the staff |
| 8–9 | Further marks below the staff |

A space means no note. Prefix symbols (ornaments, slashes, `\1`–`\4`) belong
to the note that follows them and do not take a position of their own. A `-` in
a note position is a vertical "play simultaneously" bar, not padding.

Bass courses share position 7: `a` = course 7, `/a` = 8, `//a` = 9, `///a` = 10;
`4`, `5`, `6` = open courses 10, 11, 12.

Frets: `a`–`i` = 0–8, `j` = 8 (alias of `i`), `k` = 9, `l` = 10, up to `p`.
Italian style (`$numstyle=italian` or `-i`): digits `0`–`9`, `x` = 10,
`y` = 11, `z` = 12, `Nxx` = fret xx.

`-tuning` lists courses from the lowest to course 1 (the program reads it right
to left). Octave digits count downward: an octave starts at `a`, and `4` is the
lowest octave. A 10-course Renaissance lute in G is
`-tuning C4D4E4F4G4c3f3a2d2g2`. `+` = sharp and `-` = flat.

## Support in Oud

Status after a load → save → load round trip, checked 2026-09-29 against the
manual and the reference parser. **Lost** means the construct is read but
dropped silently, which violates the `C15` rule.

| Construct | Status | Notes |
|---|---|---|
| Chord lines, courses 1–6, letters `a`–`i`, `k`–`p` | Supported | |
| Fret letter `j` | Lost | Dropped on read; should be fret 8 |
| Flags `0`–`5`, `W`, `w`, `x` (repeat flag) | Supported | Values survive; source flag characters do not |
| Dotted flag `2.` | Supported | |
| Breve `B`, longa `L` | Partial | Read as whole notes |
| Grids `#2`, `x` | Partial | Durations survive; the grid (beam) is lost |
| Triplet `t3` | Lost | The `t3` chord is dropped |
| Rests `R2`, `R!` | Lost | Dropped on read, so bar timing changes |
| Rest in a note line (`2R`) | Partial | Read as an empty chord |
| Bass courses (position 7) | Lost | Only courses 1–6 are read on open; the slash and digit encoding is not implemented |
| Italian digits | Partial | Read; saved back as letters unless the style is Italian |
| Italian `x` (10) | Supported | `y`, `z`, and `Nxx` are not |
| `Nxx` high fret | Wrong | Read as frets on other courses |
| Prefix ornaments `+ * # x $ <`, slurs `[ ] ( ) { }`, holds `U X` | Wrong | The symbol takes a course position, so the note lands on the wrong course |
| Postfix ornaments `&+`, fingering `.` `:` `\|` | Lost | The note survives; the mark is dropped |
| Left-hand fingering `\1`–`\4` | Wrong | Read as an extra note |
| Music line `M` (pitch, clef, beams, ties), `MG`, `MF` | Lost | |
| Chord text `T` | Lost | |
| Barline `b` | Supported | |
| Barline variants `bb`, `.bb.`, `b!`, `bT`, `bQ`, `bX`, `b2`, `bv` | Lost | Read as a plain barline |
| Thick barline `B` alone | Wrong | Read as a whole-note chord |
| Time signatures `S3-4`, `S12-8`, `SC`, `Sc\|` | Partial | Meter kept; the drawing variant is not |
| Titles and text `{…}`, `{a/b}` | Supported | |
| Text above a system `[…}` | Lost | |
| Comments `%`, option lines `-…`, `$` settings | Lost | Only `-tuning` and `$time` are read |
| `-tuning` | Wrong | Oud writes scientific pitch low-to-high, e.g. `g2c3f3a3d4g4`, which the program reads with inverted octaves |
| Blank lines (system breaks) | Lost | |
| `e` end marker | Supported | |
| Key `k`, fermata `Y`/`y`, `p`, `P`, `V`, `I`, `i`, `j`, `f`, `d`, `D`, `Q`, `O`, `A`, `*A`, `~` | Lost | |

## Known export defects

- Chord lines are padded with `-`, which the program draws as vertical bars on
  every padded course. Pad with spaces or trim.
- Every save adds `% Generated by oud` and `-C`. `-C` makes the program print
  every fifth bar number.
- `-tuning` notation, see above.
